# 镜像分发

Apple Container 使用 OCI 镜像格式，可以直接连接 Docker Hub、GitHub Container Registry 等标准仓库。它支持登录、打标签、推送和拉取镜像，操作方式与 Docker 类似。

本项目没有发布公共运行镜像。最终镜像包含深信服 aTrust 的闭源文件，目前没有取得公开再分发这些文件的授权。仓库中的 MIT 许可证只覆盖本项目和上游开源代码，不覆盖 aTrust 本身。

## 在自己的设备间迁移

如果所在机构的许可允许，可以把本地镜像存入自己的私有 OCI 仓库。下面以 GitHub Container Registry 为例：

```bash
export GHCR_USER="你的 GitHub 用户名"
export GHCR_TOKEN="具有 packages 权限的令牌"

printf '%s' "${GHCR_TOKEN}" | \
  container registry login ghcr.io \
    --username "${GHCR_USER}" \
    --password-stdin

container image tag \
  atrust-lite-runtime:local-arm64 \
  "ghcr.io/${GHCR_USER}/tunlet-mac:2.5.16.20-arm64"

container image push --platform linux/arm64 \
  "ghcr.io/${GHCR_USER}/tunlet-mac:2.5.16.20-arm64"
```

另一台 Apple Silicon Mac 登录同一个仓库后即可拉取：

```bash
container image pull --platform linux/arm64 \
  "ghcr.io/${GHCR_USER}/tunlet-mac:2.5.16.20-arm64"

container image tag \
  "ghcr.io/${GHCR_USER}/tunlet-mac:2.5.16.20-arm64" \
  atrust-lite-runtime:local-arm64
```

GitHub Container Registry 首次推送的包默认是私有的。公开前应先确认自己拥有 aTrust 二进制文件的再分发权。
